# B:OW Rules Reference

An unofficial, SRD-style reference for the rules of the **Bleach: Online World** roleplay forum (rpforumbleach.proboards.com).

- **Read it online:** the GitHub Pages site for this repository.
- **PDF:** [`BOW_Rules_Reference.pdf`](BOW_Rules_Reference.pdf)

## What this is

The forum's rules threads (Getting Started, Forum Mechanics: Character Creation, Forum Mechanics: Roleplaying, Miscellaneous Rules, and the Quick Reference) rewritten into one reference with short sections and tables. No rules were added. Every number in the source threads was checked against this text, and each chapter links to the thread it comes from. Where the forum contradicts itself, a note in italics says so.

Advice on building characters and roleplaying is kept apart from the rules in *Advice* boxes. Application passwords and personal staff asides are left out on purpose.

**If anything here differs from the forum, the forum is authoritative.** All rules are the work of the Bleach: Online World staff and members. This project is not affiliated with Bleach or its rights holders.

## Editing

The chapters are Markdown files in [`source/`](source/), one per chapter. `source/build_srd.py` turns them into the web page and the print version used for the PDF (`source/pdf_srd.js`, with Playwright).
